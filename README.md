# Johanna Marie Portfolio

Personal portfolio website for **Johanna Marie**, a Marketing Specialist / Content Writer.

**Live website:** [johannamarie-star.github.io](https://johannamarie-star.github.io/)

## Project status

The site is published as a work in progress. Some résumé, project, contact, portrait, and testimonial content remains as editable placeholder content until Johanna supplies the final details.

## Technology

- Next.js and React
- TypeScript
- GitHub Actions
- GitHub Pages

## Local development

Use Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

## Checks

```bash
npm run check
```

Every update pushed to `main` is checked and published automatically.
